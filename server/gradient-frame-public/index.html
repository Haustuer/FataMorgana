FataMorgana Protocol v1.0

A UDP-based multicast protocol for distributed LED display systems.


Network Architecture:

  • 📡 Server → Devices: Multicast (239.255.42.1:7777)
  • 📨 Devices → Server: Unicast (Response Port 7778)

Frame Types:

  • ⚙️ Type 0: Config Frame (Discovery)
  • 🖼️ Type 1: Image Start
  • ➡️ Type 2: Image Continuation

API Endpoints:

GET  /api/config    - Server configuration
POST /api/discover  - Trigger device discovery
GET  /api/devices   - List discovered devices
GET  /api/coverage  - Calculate coverage map
POST /api/frame     - Send image frame
